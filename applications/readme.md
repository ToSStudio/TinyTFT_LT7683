# Applications

This folder contains finished, purpose-driven applications built on the **TinyTFT_LT7683** platform.

Unlike the `/examples` folder, these sketches are complete instruments rather than demonstrations.

---

## Available Applications

### T85_GPS_UTC_Instrument
A fully functional GPS-disciplined UTC clock running on an **ATtiny85**  
driving a 10" LT7683 TFT over I²C.

Features:

- Large 7-segment UTC display
- Date + DOW
- Latitude / Longitude
- Satellite count
- HDOP bars
- Altitude
- GPS state indicators

Runs at ~99% flash usage (bootloader retained) and has been soak-tested for long-term stability.
